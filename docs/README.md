# 📚 Documentación y Reportes (docs)

Este directorio funciona como repositorio de literatura, normativa, diccionario de datos y entregables del Trabajo de Grado.

## 📄 Contenido
- **diccionario_datos.md:** Guía técnica con la descripción, tipo y unidad de medida de cada variable utilizada en los modelos.
- **01_Introduccion_Tesis_APA.docx / Tesis_Estructura_Final.docx:** Borradores base y documentos de Word con textos estructurados de la investigación.
- **/normativa:** Contiene regulaciones oficiales y manuales (como normativas CREG y la norma ISO 50001).
- **/Bibliografia:** Repositorio de referencias, artículos y textos académicos.

*(Nota: Los archivos temporales o notas sueltas como "Tips de redaccion" se mantienen ignorados por Git).*
