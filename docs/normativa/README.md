# ⚖️ Marco Normativo Regulatorio (docs/normativa)

Este directorio agrupa la documentación legal y técnica que rige el uso eficiente de la energía y las penalizaciones por consumo de energía reactiva en Colombia y a nivel internacional.

## 📄 Documentos Clave
- **Normativa CREG:** (Resolución 015 de 2018 y 199 de 2019). Bases para el cálculo y penalización (factor multiplicador M) del Cargo por Transporte de Energía Reactiva (CTER).
- **ISO 50001:2018:** Sistema de Gestión de Energía. Fundamento internacional sobre el cual se articulan las recomendaciones para la Universidad Surcolombiana.
