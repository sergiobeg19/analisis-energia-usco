# Raw Data

Datos crudos sin procesar del análisis de energía.

- `Consumo_Cuentas_.xlsx`: Consumo eléctrico por cuenta y tipo de energía.
- `Pago_Cuentas.xls`: Registro de pagos y cobros mensuales por cuenta.
- `Datos_Temperatura_Media.xlsx`: Histórico de temperatura media mensual registrada para análisis de correlación.
